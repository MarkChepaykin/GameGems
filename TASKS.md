## Контекст проекта

**GameGems (Gem Blast)** — мобильная match-3 игра. Весь код в одном файле:
`C:\Users\user\Projects\GameGems\index.html` (~5800 строк, Canvas 2D + Web Audio API).

**Роли:**
- Пользователь = визионер, PM, тестировщик. Говорит ЧТО нужно.
- Ассистент = senior-разработчик. Принимает технические решения и реализует.

**Ключевые константы и структуры:**
```
COLS = 7, ROWS = 9  (размер поля)
SPECIAL = { NONE:0, STRIPE_H:1, STRIPE_V:2, BOMB:3, RAINBOW:4, MEGA:5 }
LEVELS[]  — массив объектов уровней
state     — глобальный объект состояния игры (сохраняется в localStorage)
SKINS     — палитры цветов; SKIN_EMOJI — emoji-наборы по id скина
EPISODE_LABELS = { 1, 17, 31, 51, 71, 86, 101 }  — начала глав (по механике)
```

**Ключевые функции:**
```
processMatches()       — главный цикл матчей (async)
triggerSpecial()       — активация спецфишки
triggerCombinedSpecial() — комбо спецфишек
applyGravity()         — гравитация
fillFromTop()          — заполнение поля сверху
animateDrop()          — анимация падения (easeOutBounce)
checkWin()             — проверка победы
calcStars()            — подсчёт звёзд (33%/66%/100% прогресса)
patchLevelBalance()    — авто-балансировка ходов при старте
canSwap(r1,c1,r2,c2)   — проверка допустимости хода
findBestHint()         — поиск лучшей подсказки → [r,c,nr,nc]
showScreen(name)       — смена экрана + запуск музыки
saveGame() / loadGame() — localStorage persist
showToast(msg)         — всплывающее сообщение
```

**Dev-режим:** `?dev=1` в URL — панель отладки (+ходы, победа, телепорт по уровням).
